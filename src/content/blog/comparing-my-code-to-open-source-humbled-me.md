## The Confidence Before the Fall

I had just finished a CLI calculator in Java. It worked. No bugs. I felt like a real developer.

Then I opened a random open‑source project on GitHub — a small utility library with a few hundred stars.

## The Humble Pie

Their code was:
- Documented (every function had a clear comment)
- Tested (a folder called `tests/` I didn’t even know how to run)
- Organized (files split by purpose, not dumped in one folder)

My calculator was a single 300‑line file with comments like `// this does something`.

## The Shame Spiral (Brief)

For an hour, I felt behind. Like I had been playing while others trained.

Then I realized: those contributors had years of practice. I had months. Comparison is only useful if it teaches you something.

## What I Changed

- Started writing docstrings for every function
- Learned `unittest` in Python and JUnit in Java
- Broke my scripts into smaller files with clear imports

## The Small Win

Last week, a classmate looked at my code and said: “This is really clean.”

I smiled and thought of that open‑source project. Still not there yet. But closer.
